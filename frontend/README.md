Locora - Frontend

Setup

1. Install dependencies:

```bash
cd frontend
npm install
```

2. Set up local env:

```bash
cd frontend
cp .env.example .env.local
```

3. Run dev server:

```bash
npm run dev
```

4. Edit `VITE_API_URL` in `frontend/.env.local` to point to your backend if needed.

Deployment

- Deploy to Vercel; set `VITE_API_URL` to the backend URL on Render.
